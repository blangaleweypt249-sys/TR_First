# Hand_Shank 遥控数据帧说明

遥控器通过 USART6 将二进制数据发送到串口 Wi-Fi 透传模块；机器人侧 Wi-Fi 模块将原始数据输出到 H723 UART9。现有 8 字节协议保持不变。

## 通信参数

- 波特率：115200
- 数据位：8
- 停止位：1
- 校验：无
- 帧周期：20 ms
- 帧长度：8 字节

## 数据帧格式

```text
A5 5A BYTE2 BYTE3 BYTE4 BYTE5 BYTE6 BYTE7
```

| 字节偏移 | 字段 | 说明 |
|---:|---|---|
| 0 | `A5` | 帧头第 1 字节 |
| 1 | `5A` | 帧头第 2 字节 |
| 2 | `BYTE2` | 摇杆数据：低 4 位为 X，高 4 位为 Y |
| 3 | `BYTE3` | 第 1 组按键 |
| 4 | `BYTE4` | 肩键 |
| 5 | `BYTE5` | 第 2 组按键 |
| 6 | `BYTE6` | 第 3 组按键 |

## 按键与字节对应关系

所有按键均为低电平按下，协议位为 `1`；松开时协议位为 `0`。

### BYTE3：第 1 组（不含肩键）

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PA6 | 按键 |
| bit1 | PA5 | 按键 |
| bit2 | PA4 | 按键 |
| bit3 | PA1 | 按键 |
| bit4 | PA0 | 按键 |
| bit5 | PC3 | 按键 |



### BYTE4：肩键

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0~bit3 | ADC_CHANNEL_7 | ADC 量化值，范围 `0x0~0xF` |
| bit4~bit7 | ADC_CHANNEL_11 | ADC 量化值，范围 `0x0~0xF` |

### BYTE5：第 2 组
### BYTE6：第 3 组

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PA12 | 按键 |
| bit1 | PE6 | 按键 |
| bit2 | PE3 | 按键 |
| bit3 | PE4 | 按键 |
| bit4 | PE5 | 按键 |
| bit5 | PE2 | 按键 |
| bit6 | PE1 | 按键 |
| bit7 | PE0 | 按键 |

### BYTE7：第 4 组

| 位 | 手柄输入 | 说明 |
|---:|---|---|
| bit0 | PD3 | 按键 |
| bit1 | PD4 | 按键 |
| bit2 | PD7 | 按键 |
| bit3 | PD6 | 按键 |
| bit4 | PD5 | 按键 |
| bit5~bit7 | 保留 | 当前发送为 `0` |

H723 接收端使用 UART9 中断逐字节寻找 `A5 5A`，收满 8 字节后更新遥控状态。
## Wi-Fi 模块接入

- 本工程采用预配置串口 Wi-Fi 透传方案，参数集中在 `User/wifi_config.h`。
- 手柄 PC6 / USART6_TX 接模块 RX，PC7 / USART6_RX 接模块 TX，两端共地，并核对模块供电和串口电平。
- 模块串口配置为 115200、8N1；手柄每 20 ms 通过 DMA 发送 8 字节。
- 使用模块配套工具配置 SSID、密码、TCP/UDP 模式、目标 IP 和端口；机器人侧模块配置为匹配的对端，将网络载荷原样输出到 UART9。两端必须支持二进制透传，不添加文本、换行或网络状态前缀。
- 当前未指定 Wi-Fi 模块型号，因此固件不发送 AT 指令，也不负责入网、建连、重连或检测网络连接状态；这些由模块的透传固件负责。普通 AT 固件不能直接替代已配置好的透传模块。
- 烧录前完成模块配置；上机检查对端是否持续收到 `A5 5A` 开头的 8 字节帧，并验证断网及重连后的行为。
